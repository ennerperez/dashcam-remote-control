# Tiny YOLOv2 model

`tinyyolov2-7.onnx` is the ONNX Model Zoo Tiny YOLOv2 model, trained on Pascal VOC. It detects 20 classes. The model README declares MIT; its Hugging Face metadata labels the model Apache-2.0.

- Source: https://huggingface.co/onnxmodelzoo/tinyyolov2-7
